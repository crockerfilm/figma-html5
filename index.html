First install

  1. Unzip the download. You get a folder named after the plugin, like Copy Motion.
  2. Move that folder somewhere permanent, for example Documents/Figma Plugins. Figma runs the plugin from this folder, so don't leave it in Downloads.
  3. In the Figma desktop app: Plugins → Development → Import plugin from manifest… and pick manifest.json in that folder.
  4. Run it from Plugins → Development.

Updating

When a new version is out, the plugin shows a notice at the top of its panel. Your version is in the panel too.

  1. Download the new version above and unzip it.
  2. Drag the files from the new folder into the folder you installed the plugin from and choose Replace.
  3. Close and reopen the plugin. No need to import it again.

Copy Motion: what converts

Works well

  • Fades and slides (matched to Figma's playback)
  • Scale, rotation, diagonal and custom moves (flagged so you compare with Figma)
  • Hand-placed position, opacity, rotation and scale keyframes
  • Any banner size; photos, cutouts and vectors

Not yet

  • Size, path-draw and per-letter text animation
  • Animated colour, blur or corner radius
  • Timelines over about 3 s at 2 plays: choose Plays once (the banner says what fits)

It only works on the page that's open and only changes animation, with a restore point before every change. Locked layers and main components are left alone. Every banner gets its checks; look over every one before handing off.
