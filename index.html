Figma banners to HTML5, ready to deliver

A Figma plugin that copies animation across a banner suite, then exports every banner as an ad-ready HTML5 zip with its backup image, built to Google's display specs.

Install (once)

  1. Unzip it and move the Copy Motion folder somewhere it can stay, like Documents/Figma Plugins.
  2. In the Figma desktop app: Plugins → Development → Import plugin from manifest… and pick manifest.json in that folder.
  3. Run it from Plugins → Development → Copy Motion.

Update

  1. Download the latest zip above and unzip it.
  2. Replace the files in your Copy Motion folder with the new ones, in the same place.
  3. That's it: no need to import again. The plugin's footer shows its version, so you can check it matches.

What it does

  • Copy animation from one hero banner to every banner that shows the same thing: same copy, same image or same component, at every size. Previewed first, with a restore point before every change.
  • Export HTML5: one zip per banner with an empty clickTag for the ad server, under 150 KB, animation that stops within 15 s, and a backup JPG under 50 KB beside it.
  • Preview every banner playing side by side before you download, with each one's checks.
  • Delivery folders: give each version a code and the download comes out named and organised, ready to send.

It only ever reads and changes the page you're on, and it only changes animation: layers are never moved, edited or deleted. Export works on a temporary copy, so your banners aren't touched. No network access: nothing leaves Figma.

Good to know

  • Motion: fades and slides match Figma's playback. Scale, rotation, diagonal and custom moves convert too, and are flagged so you compare the preview with Figma. Size, path-draw and per-letter text animation, and animated colour, blur or corner radius, can't convert: the banner says which layer, and it stays still.
  • Plays: the default is 2 plays with a pause, which suits animations of a few seconds. A longer animation needs Plays: once to stay within 15 s; the banner's checks say what fits.
  • Finding banners: Find every banner on this page picks up frames named by their size, like 300x250. Otherwise, select the banners or the frame they sit in.
  • Specs: the limits are Google's rules for HTML5 display (DV360, Campaign Manager 360, Ad Manager). Briefs for other platforms may need different numbers.
