Install and update

Same steps for both plugins
You need the Figma desktop app. Plugins installed this way don't appear in Figma in the browser.

First install

  1. Unzip the download. You get a folder named after the plugin, like Copy Motion.
  2. Move it somewhere permanent, like Documents/Figma Plugins. Figma runs the plugin from there, so don't leave it in Downloads.
  3. In the Figma desktop app: Plugins → Development → Import plugin from manifest… and pick manifest.json in that folder.
  4. Run it from Plugins → Development.

Updating

When a new version is out, the plugin shows a notice at the top of its panel.

  1. Download the new version above and unzip it.
  2. Drag its files into the folder you installed from and choose Replace.
  3. Close and reopen the plugin. No need to import it again.
Something not working?
There's no Plugins → Development menu

You're in Figma in the browser. Open the file in the Figma desktop app.

I can't pick manifest.json

Unzip the download first, then pick manifest.json inside the plugin's folder, not the zip.

The update didn't change anything

Replace the files in the same folder you first imported from, then close and reopen the plugin. The version shows in the panel.

The plugin disappeared

Its folder was moved or deleted. Put it somewhere permanent and import manifest.json again from there.

Plugin details

What each one handles, and what's changed

What it handles

Works well

  • Fades and slides, matched to Figma's playback
  • Scale, rotation, diagonal and custom moves (flagged so you compare with Figma)
  • Hand-placed position, opacity, rotation and scale keyframes
  • Any banner size; photos, cutouts and vectors

Not yet

  • Size, path-draw and per-letter text animation
  • Animated colour, blur or corner radius
  • Timelines over about 3 s at 2 plays: choose Plays once (the banner says what fits)

It only works on the page that's open and only changes animation. Locked layers and main components are left alone.

What it handles

Works well

  • A photo on one side, and the logo, headline and button on the other
  • One headline and one button
  • Any brand, colours, fonts or sizes

Not yet

  • Text over a full-bleed photo
  • No photo, or a centred product shot
  • Photo on top, copy below
  • Extra lines (subheadline, legal), added by hand

Every size is labelled pass, review or blocked; look over every one before handing off. More on its own page.
