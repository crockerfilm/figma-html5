    Changes made to each banner's index.html

    1. clickTag added to <head>. var clickTag = ""; is filled at runtime from ?clickTag= in the banner URL. The ad server can also overwrite window.clickTag directly. No landing page URL is stored anywhere.
    2. javascript: blocked. Only http:// or https:// values are accepted, both when reading the URL and again at click time.
    3. ad.size meta added. <meta name="ad.size" content="width=W,height=H">, taken from the banner's GWD stage size (falling back to GWD metadata, then the filename).
    4. Tap area rewired. Every Studio exit (gwd.actions.gwdGoogleAd.exit, Enabler.exit, and similar) now calls window.open(window.clickTag, "_blank").
    5. Studio code stripped. Remote Enabler.js (2mdn), the gwdgooglead component, the StudioExports block, <gwd-exit> tags, GWD ad metadata, and the generator / environment / template / GCD metas. The <gwd-google-ad> wrapper becomes a plain <div id="gwd-ad">.
    6. Studio start-up replaced. initAd() becomes a direct pagedeck.goToPage('page1'). Without this step the banner stays blank, because the GWD ad wrapper depends on Enabler.

    Also: Mac/Windows system files (__MACOSX, .DS_Store) are removed, and an index.html inside a subfolder is moved to the zip root. Images and other files are left untouched.

    The checks

      Live checks load each converted banner in a sandboxed browser frame three times: with no clickTag, with ?clickTag= set to a test URL, and with ?clickTag=javascript:…. Clicks are simulated, and window.open is intercepted so nothing actually opens. These checks can't judge how the banner looks, so use the QA preview for that.
